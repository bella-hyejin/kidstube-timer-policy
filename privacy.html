피카바라 개인정보처리방침

시행일: 2026년 11월 23일

피카바라(이하 "앱")는 보호자가 고른 YouTube 채널의 영상을 정해 둔 시간 안에서 아이가 볼 수 있게 하는 앱입니다. 앱은 회원가입이나 로그인이 없으며, 운영자가 따로 두는 서버도 없습니다(오류 보고는 아래 2번의 Firebase Crashlytics를 씁니다). 이 방침은 앱이 어떤 정보를 어디에 두는지 설명합니다.

1. 앱이 기기에 저장하는 정보

아래 정보는 모두 이 기기 안에만 저장되며, 운영자에게 전송되지 않습니다.

항목내용보관 기간
아이 프로필별명, 출생년도 (연령대 계산용)보호자가 삭제할 때까지
보호자 설정PIN(원문이 아닌 변환값으로 저장), 지문 사용 여부, PIN 연속 실패 횟수와 잠금 해제 시각, 승인한 채널 ID, 숨긴 영상 ID, 시청 시간·필터 설정
시청 기록세션별 시작 시각·정한 시간·다 보고 나서 할 일, 본 영상과 그 채널의 ID, 본 시각, 앱이 직접 잰 시청 시간
지문앱은 지문 정보를 받지 않습니다. 확인은 Android 시스템이 하고 앱은 성공 여부만 받습니다
YouTube에서 받은 정보채널명, 썸네일, 영상 제목·길이 등받은 날로부터 30일 이내 삭제 또는 갱신

앱은 아이의 실명, 생년월일, 사진, 이메일, 위치, 광고 ID 등 기기 고유 식별자를 수집하지 않습니다.

2. 외부로 전송되는 정보

앱은 YouTube API 서비스를 사용합니다. 영상 목록을 불러오고 재생하기 위해 채널·영상 ID와 썸네일 이미지 요청이 Google(YouTube)로 전송되며, 재생 중에는 YouTube 플레이어가 동작합니다. 이 과정에서 Google이 처리하는 정보에는 Google의 정책이 적용됩니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

앱이 비정상 종료되면 원인을 찾아 고치기 위해 Google의 Firebase Crashlytics로 오류 보고가 전송됩니다. 오류 보고에는 오류가 난 코드 위치, 기기 모델·OS 버전·화면 방향·남은 저장 공간 같은 기기 상태, 앱 버전, 그리고 앱 설치마다 무작위로 만들어지는 설치 식별자가 들어갑니다. 설치 식별자는 앱을 지우면 사라지며 광고 ID나 기기 고유 식별자가 아닙니다. 아이의 별명·출생년도, 승인한 채널, 시청 기록은 오류 보고에 넣지 않습니다. 오류 보고는 Google 서버에 90일 동안 보관된 뒤 삭제됩니다.

  • Firebase의 개인정보 보호 및 보안

앱에는 광고 SDK와 사용 분석 SDK가 없습니다. 위 외에는 어떤 정보도 외부로 보내지 않습니다.

3. 아동의 개인정보

앱은 만 14세 미만 아동이 사용하는 것을 전제로 만들어졌습니다. 아이에게서 정보를 직접 받지 않으며, 별명과 출생년도는 보호자가 입력하고 기기에만 저장됩니다.

4. 정보 삭제

  • 앱 안에서: 보호자 화면 → 설정 → "모든 데이터 삭제"를 누르면 기기에 저장된 정보가 즉시 모두 지워집니다.
  • 앱을 삭제하면 기기에 저장된 정보도 함께 지워집니다.
  • 운영자가 보관하는 것은 2번의 오류 보고뿐이며 90일 뒤 자동으로 삭제됩니다. 그 전에 삭제를 원하거나 문의가 있으면 아래 연락처로 알려 주세요. 7일 이내에 답변드립니다.
